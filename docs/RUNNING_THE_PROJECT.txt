STARTING THE PROJECT
====================

STEP 1: Start the Honeypot (Terminal 1)
--------------------------------------
python src/main.py

Expected output:
  [*] PhantomPot -- multi-protocol honeypot starting ...
  [*] Press Ctrl-C to stop all listeners.

The system will listen on:
  - SSH:    localhost:2222
  - HTTP:   localhost:8080
  - FTP:    localhost:2121
  - Telnet: localhost:2323


STEP 2: Run KPI Evaluation (Terminal 2, after 5-10 seconds)
----------------------------------------------------------
python scripts/evaluate_objective4.py --intensity medium --output eval_report.json

This simulates 25 attack scenarios and measures:
  1. Attack Detection Rate (TP/FP classification)
  2. Protocol Coverage (4 active protocols)
  3. Logging Accuracy (data loss detection)
  4. System Response Time (connection-to-log latency)

Expected runtime: 5-10 minutes


STEP 3: Generate Reports (Terminal 2)
------------------------------------
python scripts/generate_kpi_report.py --eval eval_report.json --format all

Generates:
  - objective4_report-TIMESTAMP.json    (machine-readable)
  - objective4_report-TIMESTAMP.md      (markdown)
  - objective4_report-TIMESTAMP.html    (visual report)


STEP 4: View Dashboard (Terminal 3)
---------------------------------
streamlit run dashboard/app.py

Then open: http://localhost:8501
Navigate to: "KPI Metrics (Objective 4)" tab

FOUR KPIs EXPLAINED
===================

1. ATTACK DETECTION RATE
   - True Positive Rate (target: >=90%)
   - False Positive Rate (target: <=5%)
   - Precision, Recall, F1-Score
   
2. PROTOCOL COVERAGE
   - Active protocols: SSH, HTTP, FTP, Telnet (target: 4/4)
   - Sessions per protocol
   
3. LOGGING ACCURACY
   - Sessions fully logged without data loss (target: >=99.9%)
   - Command & login coverage
   
4. RESPONSE TIME
   - Average latency in milliseconds (target: <=10ms)
   - P95, P99 percentiles

TROUBLESHOOTING
===============

Port already in use:
  lsof -i :2222  (find process)
  kill -9 PID    (kill process)

Import errors:
  pip install -r requirements.txt

SSH host key missing:
  python gen_ssh_key.py

Dashboard won't connect:
  Check that honeypot is running in Terminal 1
  Try: streamlit run dashboard/app.py --logger.level=info
